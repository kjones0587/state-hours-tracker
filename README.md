# State Hours Tracker

A simple phone-friendly web app for tracking hours worked in two states (Illinois / Wisconsin) with separate pay rates.

- One-tap clock in/out per state; switch states mid-shift without double counting
- Weekly, pay-period, and monthly totals with estimated pay per state
- Add or edit missed time, CSV export, JSON backup/restore
- Works offline and installs to the home screen (PWA)
- All data stays in the browser on the device. No account, no server, no tracking.

Built with plain HTML/CSS/JavaScript, no dependencies.
